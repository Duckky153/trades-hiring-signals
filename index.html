      Assumptions

      • ServiceTitan shops are assumed to fit best, because the estimate and follow-up data already lives there. Other software scores lower, not zero.
      • A follow-up or inside-sales opening means the shop is about to pay a salary for work that software can take on. When the pay is posted, the detail view shows what that seat costs a year.
      • Technician counts come from careers-page text like "join our team of 26 techs", so they're approximate.
      • Hiring is not buying. A posting shows a shop is growing and where work is piling up. It doesn't show that the shop will buy anything.
      • A shop with no software named isn't treated as a bad fit. It gets no software points, and goes to a person if it would otherwise be a Call this week.
      • Hourly pay is turned into a yearly figure at 2,080 hours. Ages are counted from the data date, Sep 30, 2026.

      What I'd need to run this on real data

      • The job boards and careers pages to read, and which metros matter.
      • A list of current customers to exclude, so nobody calls a shop that already buys.
      • The field-service software you support, and how well each one works, to set the software points.

      Everything else here (the gates, the caps, the holds) runs the same way on real postings.

      Questions I'd want answered

      Each rule above is a guess. These are the answers that would change it.

      1. When a shop names ServiceTitan in a job post, is that enough to call it a fit, or do you confirm the software another way first?
      2. Is a shop hiring an estimate follow-up or inside-sales person a buyer for you, or a sign they've already solved follow-up with people?
      3. Which predicts a good account better: technician count, or how many estimates a shop writes a month?
      4. Do franchise locations buy on their own, or does it go through head office?
      5. Should commercial work count at all, or only residential repair and replacement?
